# Hubit

We build **Hubit Panel**, a self-hosted system for selling and managing VPN subscriptions.

It connects to your **PasarGuard** or **3x-ui** panel and runs the whole sales side for you: an admin panel, a reseller panel with wallets, a customer web app and a Telegram bot with a Mini App. Payments, renewals, refunds, usage and backups are automatic, and the interface is available in English and Persian.

## What we care about

- **Simple to run.** One command installs everything on a Linux server, with automatic HTTPS. Updates install from inside the panel.
- **Yours, not ours.** The panel runs on your own server and your own domain. Your customers' subscription links stay the same even if the panel behind them changes.
- **Built for sellers.** Resellers, discount codes, referral rewards and a clear change log are part of the product, not add-ons.

## Get started

Install Hubit Panel with one command: see the README of [hubit-git/panel](https://github.com/hubit-git/panel).
